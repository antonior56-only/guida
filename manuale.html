1. Come funziona GuidaPA (PC, Telefono e Offline)

GuidaPA è progettata su misura per una guida turistica abilitata che lavora su chiamata di agenzie, tour operator e compagnie crocieristiche tra Palermo, Monreale e Cefalù. Unisce due momenti di lavoro distinti:

  • A casa / alla scrivania (PC o tablet): raccogli in un unico posto le richieste che arrivano sparse su WhatsApp ed email, controlli subito sovrapposizioni d'agenda o chiusure dei monumenti, calcoli il preventivo col listino dedicato di ciascuna agenzia, invii il PDF e tieni sotto controllo fatture e scadenze d'incasso.
  • Sul campo coi turisti (Smartphone, anche senza rete): controlli i tempi di ogni tappa rispetto all'orario limite di rientro nave/volo, conti rapidamente i partecipanti, mostri il QR del punto di ritrovo, attivi in un tocco il Piano Pioggia al coperto, consulti aneddoti con Gemini AI, mandi messaggi rapidi all'autista e a fine servizio invii il report all'agenzia.
Funzionamento ibrido Offline + Cloud: ogni modifica viene salvata all'istante nella memoria interna del dispositivo (localStorage), così non perdi mai nulla nemmeno dentro una chiesa o nei vicoli di Ballarò senza segnale. Quando configuri JSONBin.io, l'app sincronizza automaticamente i dati tra il tuo PC e il tuo telefono appena c'è connessione.

2. Pubblicare gratis l'app su GitHub Pages

Pubblicare la cartella su GitHub Pages ti fornisce un indirizzo web personale gratuito del tipo https://tuonome.github.io/guidapa/, necessario per aprire e installare l'app sul telefono. Non serve installare alcun programma sul computer.

Procedura passo-passo dal browser (10 minuti una sola volta)

  1. Crea un account gratuito su https://github.com (oppure accedi se ne hai già uno) e conferma il tuo indirizzo email.
  2. In alto a destra clicca sul pulsante + → New repository.
  3. Nel campo Repository name scrivi guidapa. Lascia selezionato Public (necessario per avere GitHub Pages gratis), spunta Add a README file e clicca sul pulsante verde Create repository.
  4. Nella pagina del repository appena creato clicca su Add file → Upload files.
  5. Apri sul computer la cartella guidapa, seleziona tutti i file principali (index.html, style.css, app.js, cloud_ai.js, tour.js, data.js, qrcode.js, manifest.json, sw.js, icon.svg, .nojekyll, manuale.html, Manuale_Uso_GuidaPA.pdf) e trascinali nel riquadro del browser. Attendi il completamento del caricamento e premi il pulsante verde Commit changes.
  6. In alto nel repository clicca sulla scheda Settings (icona ingranaggio) e nel menu a sinistra clicca su Pages.
  7. Sotto Build and deployment → Source scegli Deploy from a branch; sotto Branch seleziona main e la cartella / (root), quindi premi Save.
  8. Attendi 1–2 minuti e ricarica la pagina Settings → Pages: comparirà in alto il tuo link attivo (es. https://tuonome.github.io/guidapa/).
Importante sulla privacy su GitHub: i file caricati su GitHub contengono solo il programma vuoto, mai i tuoi clienti, le tue tariffe reali o le tue chiavi segrete. Tutti i tuoi dati personali viaggiano esclusivamente sul tuo browser e nel tuo archivio privato protetto da chiave su JSONBin.io. Non caricare mai su GitHub i file guidapa-backup-*.json.

4. Salvataggio Cloud con JSONBin.io (PC ↔ Telefono)

JSONBin.io è un servizio cloud gratuito che custodisce in un archivio privato (chiamato Bin) tutti i tuoi servizi, le agenzie, i siti e il profilo, mantenendo allineati computer e smartphone.

Configurazione sul primo dispositivo (es. Computer)

  1. Vai su https://jsonbin.io e registrati gratuitamente (puoi accedere direttamente col tuo account Google).
  2. Apri la pagina delle chiavi API: https://jsonbin.io/app/app/api-keys (raggiungibile anche dal link diretto dentro GuidaPA in ⚙️ Profilo e dati).
  3. Copia il codice mostrato sotto X-Master-Key (inizia solitamente con $2a$10$... o $2b$10$...).
  4. In GuidaPA apri ⚙️ Profilo e dati → ☁️ Salvataggio Cloud (JSONBin.io) e incolla il codice nel campo JSONBin Master Key.
  5. Clicca sul pulsante ✨ Crea nuovo archivio (Bin): GuidaPA creerà automaticamente un archivio privato, compilerà da sola il campo Bin ID e invierà i tuoi dati.

Collegamento del secondo dispositivo (es. Smartphone)

  1. Apri GuidaPA sullo smartphone e vai in ⚙️ Profilo e dati → ☁️ Salvataggio Cloud.
  2. Incolla la stessa Master Key e lo stesso Bin ID generato sul computer.
  3. Premi 💾 Salva impostazioni Cloud e subito dopo ⬇️ Scarica da Cloud: ritroverai istantaneamente tutte le tue agenzie e i tuoi servizi!

5. Assistente AI Google Gemini (creazione API Key e uso)

Integrando la tua chiave gratuita di Google Gemini, hai un assistente storico-culturale personale pensato per chi guida gruppi a Palermo, Monreale e Cefalù.

Come creare gratuitamente la API Key su Google

  1. Apri il link ufficiale (presente anche dentro l'app): https://aistudio.google.com/apikey accedendo col tuo account Google.
  2. Clicca sul pulsante blu Create API key (se richiesto, accetta i termini e scegli Create API key in new project).
  3. Copia la stringa generata (inizia con AIzaSy...).
  4. In GuidaPA apri ⚙️ Profilo e dati → ✨ Assistente AI (Google Gemini), incolla la chiave e premi 💾 Salva chiave Gemini. Puoi verificare subito che tutto funzioni col tasto 🧪 Testa connessione Gemini.

Cosa puoi chiedere a Gemini prima e durante il tour

Premendo ✨ Approfondisci con Gemini (nella scheda servizio) oppure ✨ Chiedi a Gemini / l'icona ✨ accanto a ogni tappa (in Modalità Tour), l'assistente conosce già automaticamente le tappe scelte, la lingua del gruppo, il numero di partecipanti e le eventuali esigenze speciali:

  • 🎭 Aneddoti e curiosità: dettagli iconografici, storie poco note e leggende popolari (distinguendo sempre la storia documentata dalla leggenda).
  • 🌍 Legami col paese/lingua del gruppo: es. legami normanni o inglesi (Guglielmo II e Giovanna d'Inghilterra, gli Ingham-Whitaker), svevi/tedeschi (Federico II), francesi, spagnoli/aragonesi.
  • 🍋 Gastronomia e tradizioni vicine: origine araba e monastica dei piatti, street food dei mercati storici, dolci delle feste.
  • 🗣️ Frasi e termini nella lingua del tour: introduzione pronta e mini-glossario tecnico (es. muqarnas, chiostro binato, tarsie laviche, pantocratore) già tradotto nella lingua degli ospiti.
  • Domanda libera di un turista: scrivi qualsiasi curiosità emersa durante la passeggiata.
📌 Trucco per lavorare senza rete: quando prepari il tour da casa (o mentre hai campo), clicca su 📌 Salva offline nel tour sopra le risposte migliori di Gemini. Gli appunti resteranno salvati dentro quel servizio e potrai leggerli in Modalità Tour anche dentro il Duomo o nei vicoli senza connessione!

6. Configurazione iniziale: Profilo, Agenzie e Siti

  • ⚙️ Profilo e tariffe: inserisci nome, cognome, numero tesserino regionale, P.IVA/C.F., IBAN, condizioni di cancellazione, tariffe standard (mezza giornata, intera, ora extra, supplemento lingua, maggiorazione festiva) e i minuti medi di spostamento tra una tappa e l'altra (usati per calcolare la timeline del tour).
  • 🏢 Agenzie: registra ogni agenzia/tour operator con referente, contatti, giorni di pagamento pattuiti (es. 30 o 60 giorni) ed eventuali tariffe concordate dedicate che sovrascrivono in automatico il listino standard.
  • 🏛️ Siti e tappe: trovi già precaricati 30 siti tra Palermo, Monreale e Cefalù. Clicca Modifica su ciascun sito per inserire il costo aggiornato del biglietto, i giorni abituali di chiusura, le note operative e la spunta 🏛️ Sito al coperto (fondamentale per il Piano Pioggia). Ogni salvataggio aggiorna la data "Verificato il…".

7. Gestire le richieste dalle agenzie, Preventivi e Fatture

  1. Inserimento richiesta: clicca + Nuova richiesta in alto. Incolla nel primo riquadro il testo originale ricevuto via WhatsApp o email (rimarrà archiviato per consultazione), scegli l'agenzia, data, ora, durata, pax, lingua, punto d'incontro, eventuali contatti di capogruppo e autista, e l'orario limite di rientro (es. tutti a bordo per le crociere).
  2. Scelta tappe e controlli automatici: spunta le tappe nell'ordine desiderato. Nel pannello destro GuidaPA controlla in tempo reale:
    • ⚠️ eventuali sovrapposizioni d'orario con altri servizi già in agenda;
    • 🚫 siti abitualmente chiusi in quel giorno della settimana;
    • ⏱️ durata complessiva delle visite superiore alle ore previste;
    • calcolo automatico del compenso (o inserimento di un prezzo forfettario concordato).
  3. Preventivo in 1 clic: salva e premi 📄 Preventivo. Puoi premere 📋 Copia testo per WhatsApp/email per rispondere subito in chat, oppure 🖨️ Stampa / Salva PDF (scegliendo "Salva come PDF" nella finestra di stampa) per ottenere un documento intestato e numerato progressivamente.
  4. Dalla conferma all'incasso: aggiorna lo stato lungo il ciclo Nuova → Preventivata → Confermata → Svolta → Fatturata → Pagata. Quando segni Fatturata inserisci numero e data fattura: l'app calcola la scadenza di pagamento in base agli accordi con l'agenzia e ti avvisa nella schermata 🏠 Oggi se ci sono fatture scadute. Con 📊 Esporta servizi (Excel/CSV) scarichi il riepilogo per il commercialista.

8. Modalità Tour sul campo, QR Code e Report finale

Il giorno della visita apri la scheda 🚶 Tour (oppure tocca il pulsante arancione ▶ Modalità tour in 🏠 Oggi). La schermata mantiene attivo il display quando supportato dal telefono e offre:

  • Barra di stato e margine rientro: in cima vedi l'ora attuale, la fine prevista ricalcolata dal vivo e quanti minuti di margine hai rispetto alla fine del servizio o all'orario limite nave/volo (verde = in orario, giallo = margine sotto 15', rosso = ritardo previsto).
  • 👥 Conta partecipanti: due pulsanti giganti − e + pensati per contare il gruppo con una mano sola senza guardare lo schermo (con vibrazione sul telefono). Quando raggiungi il totale previsto il riquadro diventa verde. Se hai incollato l'elenco nominativo, puoi fare anche l'appello per nome.
  • 🗺️ Percorso live: premi ▶ Inizia all'ingresso di ogni sito e ■ Fine all'uscita. L'app mostra da quanti minuti sei nella tappa, quanto tempo resta e registra il numero di presenti contati.
  • 📍 Punto di ritrovo con QR offline: scrivi il luogo (o premi 📍 Sono qui (GPS)) e tocca +15', +20', +30' o +45' per fissare l'orario di ritrovo. Premi 🔳 QR mappa per i turisti: compare sullo schermo un grande codice QR generato offline che i turisti possono inquadrare con la fotocamera per avere subito il punto esatto su Google Maps. Con 🔳 QR WhatsApp guida permetti al capogruppo di scriverti su WhatsApp senza dettare il numero.
  • 🚌 Autista, 💶 Spese, 📝 Diario e 🆘 Emergenze: invia in un tocco messaggi WhatsApp precompilati all'autista ("Pronti tra 10'", "Ritardo 15'", "Invia posizione ritrovo"), segna eventuali spese anticipate, annota imprevisti (es. funzioni religiose improvvise) e tieni a portata di dito il 112, farmacie e pronto soccorso vicini.
  • 🏁 Chiusura tour e Report agenzia: a fine servizio premi 🏁 Chiudi tour e crea report. Il servizio passa automaticamente allo stato Svolta e si apre il resoconto completo (orari effettivi di ogni tappa, partecipanti contati, spese anticipate e note), pronto da inviare con un clic su WhatsApp o via email all'agenzia.

9. Pulsante Cattivo Tempo (Piano Pioggia al coperto)

Un acquazzone improvviso a Ballarò o il vento forte sulla Rocca di Cefalù richiedono un cambio rapido di programma. Sia nella Scheda Servizio sia direttamente in Modalità Tour (accanto al titolo Percorso) trovi il pulsante 🌧️ Cattivo tempo: al coperto.

  1. Analisi istantanea (funziona anche offline): l'app individua tutte le tappe all'aperto (☀️) non ancora svolte e propone per ciascuna la migliore alternativa al coperto (🏛️) nella stessa zona (es. Chiesa del Gesù o Oratori del Serpotta al posto dei mercati e piazze a Palermo; Museo Mandralisca o Osterio Magno al posto della Rocca o del Lavatoio a Cefalù), escludendo automaticamente i musei chiusi in quel giorno della settimana.
  2. Personalizzazione e anteprima tempi: per ogni tappa puoi scegliere dal menu a tendina un altro monumento al chiuso, mantenere la tappa o rimuoverla, confrontando subito la durata totale prima e dopo.
  3. Consigli logistici con Gemini (opzionale): premendo ✨ Consigli pioggia con Gemini ottieni suggerimenti su portici, passaggi riparati, caffè storici vicini per far sostare il gruppo all'asciutto e una frase positiva nella lingua del tour per presentare la variazione agli ospiti.
  4. Applicazione e ripristino: premendo ✅ Applica variante al coperto, le tappe già visitate vengono preservate, il percorso residuo viene aggiornato e la variazione viene annotata automaticamente nel Diario del tour (così comparirà anche nel report finale per l'agenzia). Se più tardi torna il sole, riaprendo la stessa finestra compare il tasto ☀️ Ripristina itinerario originale!

10. Sicurezza, Privacy, Backup e domande frequenti

  • Dove vengono salvate le chiavi API di JSONBin e Gemini? Esclusivamente nel tuo browser (chiave separata guidapa_secrets_v1). Non vengono mai incluse né nel codice pubblicato su GitHub né nei file guidapa-backup.json esportati.
  • Consiglio di sicurezza periodico: anche se usi JSONBin.io, una volta ogni 1–2 settimane vai in ⚙️ Profilo e dati → ⬇️ Scarica backup (JSON) sul computer: avrai sempre una copia storica offline di tutti i tuoi servizi.
  • Ho aggiornato un file su GitHub ma sul telefono vedo la versione precedente: chiudi completamente l'app sul telefono e riaprila con connessione internet attiva; il Service Worker scaricherà automaticamente i file aggiornati.
  • Posso usare GuidaPA senza JSONBin o senza Gemini? Certamente: entrambi sono facoltativi. Senza JSONBin i dati restano sul singolo dispositivo (trasferibili col file di backup JSON); senza Gemini tutte le altre funzioni (incluso il Piano Pioggia al coperto e i codici QR) continuano a funzionare al 100% offline.
